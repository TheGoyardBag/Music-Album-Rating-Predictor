# Data provenance

`demo_albums.csv` was generated by `scripts/make_demo_data.py` with seed 17.
All 600 records, 120 artists, album titles, and ratings are fictional. No real listener
ratings, copyrighted album descriptions, or scraped website data are included.

Ratings are constructed from tag weights, one pairwise interaction, an artist effect,
and random noise. This intentionally makes the dataset learnable; performance is not
representative of a real recommendation or review prediction task.

Regenerate with `python scripts/make_demo_data.py` from the repository root.
